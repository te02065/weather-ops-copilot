원본 파일은 CP949 인코딩이었고, UTF-8로 바꿔 넣었습니다. 내용은 그대로이며 줄 끝만 통일하고 맨 앞 빈 줄을 뺐습니다.
기상청 공공 자료이므로 개인정보는 없습니다. 자료를 내려받은 날짜는 파일에 적혀 있지 않습니다 [확인 필요].

확인 명령: `npm run check-stations` (행 수, 운영 지점, 강우계 기록, 좌표와 번호 오류를 검사합니다. 파일은 고치지 않습니다.)

주의: 이 목록은 참조용입니다. 실제로 쓸 지점은 `data/weather_cache/stations.json`에서 확정한 것만 씁니다.
