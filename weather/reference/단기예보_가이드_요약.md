# 단기예보 조회서비스 가이드 요약

원본: `docs/단기예보조회서비스_API활용가이드_261019.docx` (기상청 API허브 명세, 파일명 261019)
이 파일은 원본에서 필요한 부분만 옮긴 요약입니다. 자세한 내용은 원본을 보세요.

## 1. 요청 주소 (명세)

- 단기예보: `https://apihub.kma.go.kr/api/typ02/openApi/VilageFcstInfoService_2.0/getVilageFcst`
- 초단기예보: `.../getUltraSrtFcst`, 초단기실황: `.../getUltraSrtNcst`
- 예보버전: `.../getFcstVersion`

요청 변수 (단기예보)

| 변수 | 뜻 | 예 | 필수 |
|---|---|---|---|
| authKey (또는 serviceKey) | 인증키 | - | 필수 |
| dataType | XML 또는 JSON (기본 XML) | JSON | 선택 |
| numOfRows | 한 페이지 결과 수 (기본 10) | 1000 | 선택 |
| pageNo | 페이지 번호 (기본 1) | 1 | 선택 |
| base_date | 발표일자 YYYYMMDD | 20261104 | 필수 |
| base_time | 발표시각 (아래 표) | 2300 | 필수 |
| nx, ny | 예보 지점 격자 번호 | 58, 125 | 필수 |

## 2. 발표 시각과 제공 시간

- 발표 시각 8회: 0200, 0500, 0800, 1100, 1400, 1700, 2000, 2300 (상세: `short_forecast_schedule.csv`)
- 제공 시간: 발표 후 10분 뒤 (예: 2300 발표 → 23:10 이후 조회 가능)

## 3. 응답 (명세)

- 항목: baseDate, baseTime, category(항목코드), fcstDate, fcstTime, fcstValue, nx, ny
- category 설명과 단위: `short_forecast_items.csv`
- 코드값 (SKY, PTY, 강수량·적설 범주, 연장기간 정성 코드): `short_forecast_codes.csv`
- 응답 결과 코드: resultCode `00` = 정상

## 4. 예보 기간

- 앞쪽 예보 기간: 1시간 간격 수치 값 (명세 표의 정확한 구간은 원본 확인 필요)
- 연장 (02·05·08·11·14시 발표는 글피, 17·20·23시 발표는 그글피까지): 3시간 간격. 강수량, 적설, 풍속은 정성 코드
- 해상 지역: 기온군, 강수확률, 강수량, 습도 제공 안 함

## 5. 격자 (지점 번호)

- 격자 좌표표: `grid_points.csv` (동네예보 지점 3,839곳)
- 매장 칸: 금천구 가산동 (58, 125)
- 격자 값 읽기 방향: `weather/forecastGrid.ts` (맨 앞 줄이 ny=1, 남쪽)

## 6. 오류와 주의

- 우리 키로 `typ02` 주소를 부르면 403 "활용신청이 필요한 API"가 나옵니다 (2026-11-05 확인).
  - 조치: API허브에서 **단기예보 조회서비스** 활용신청 후 승인 확인.
- `typ02`에 `serviceKey` 이름으로 KMA 키를 넣으면 401 "유효한 인증키가 아닙니다" (이 주소는 `authKey` 이름 사용).
- 메모.md의 주소 `typ01/cgi-bin/url/nph-dfs_shrt_grd`는 응답이 헤더 없는 격자 숫자 목록입니다 (`weather/forecastGrid.ts` 참고). 명세의 `typ02` 주소와 형식이 다릅니다.

## 7. 아직 모르는 것 (확인 필요)

- 강수 예보 변수 POP, PCP가 메모.md 주소(`cgi-bin`)에서도 같은 방식으로 나오는지. 현재 확인된 것은 TMP 한 가지입니다.
- 활용신청 승인 후 `typ02`에서 실제 응답 형식.
